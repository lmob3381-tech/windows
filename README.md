# windows

Jalankan Windows desktop (GUI penuh) di dalam GitHub Actions, diakses lewat
browser via noVNC, dibuka ke internet pakai Cloudflare Quick Tunnel.

## Cara pakai
1. Buka tab Actions di repo GitHub ini.
2. Pilih workflow "Run Windows Desktop (noVNC + cloudflared)".
3. Klik "Run workflow".
4. Tunggu link trycloudflare.com muncul di log.
5. Buka link itu di browser, tunggu 30-40 menit sampai desktop Windows muncul.
